# Tickets for https://github.com/DmitryV13/NOT_MARIO

Tickets (bugs, tasks) for the **NOT_MARIO** project, stored as Markdown files.
Each file is named by its ID (e.g. `ABC-0001.md`) and follows `template.md`.
IDs are generated with [id-generator](https://github.com/DmitryV13/tickets_tracker).

## Generator config (`config.json`)

```json
{
  "output_dir": "C:/{absolutePath}/tickets",
  "letters_mode": "fixed",
  "letters": ["A", "B", "C", "D", "E", "F"],
  "fixed_letters": "NMT",
  "strategy": "sequential",
  "letters_count": 3,
  "digits_count": 4
}
```
